# TC-003 — No Hermes in this build: Claude Code integrates, Codex reviews, Mats approves

| Field | Value |
|---|---|
| Change | There is no build orchestrator. Claude Code is the integration owner and runs the gates; Codex reviews every integrated change; Mats approves product decisions, protected changes and the release, and he alone commits, signs, pushes, publishes and submits. |
| Reason | The baseline assumed Mats would operate Hermes on a workbench. He is not, so every rule that hung off Hermes was either unowned or an instruction to a process that does not exist — including the protected-inputs control that the whole solo-author CI model depends on. |

## Decisions rewritten

- **D9** now states the execution model plainly and is **accepted** rather than "decided,
  workbench policy outside this package".
- **D28** is **declined**. It was the *fallback to* Hermes ("Claude Code in one rootless
  container, if Mats accepts it after a read-only Hermes inventory"). With no orchestrator
  there is nothing to fall back from, and the controls it asked about are now in
  BUILD-PACKAGES §2.1 and PLAN §8.
- The status word **"outside this package"** is retired from PLAN §0: it was defined as
  "Mats's workbench policy", which no longer exists.
- **D12**, **D38** and **D48** lose their "workbench" wording for accurate phrasing
  ("the build environment on Mats's machine", "bound to host loopback", "independent of the
  build machine").

## A contradiction this resolves

HERMES-P0 §1 forbade Claude Code from executing project code ("Never: Execute project
code, commit, push"), while PLAN §9 said "Run `check.sh` before Mats commits" and
BUILD-PACKAGES §5 made running the gates an integration duty. TC-003 settles it:
**Claude Code runs the gates and the test suite; Mats alone commits, signs, pushes,
publishes and submits.**

## Public claims

Mats's instruction was to keep the narrative strictly true. COMPETITION §14.4 (renamed
from "Model, workbench and claims" to "Model, build tooling and claims"), §14.1 and the
post outline now say: built with Claude Code as integration owner and Codex as reviewer,
with Mats approving decisions, protected changes and the release and making every commit
and publication himself — and explicitly warn against claiming an orchestration layer this
build does not have.
