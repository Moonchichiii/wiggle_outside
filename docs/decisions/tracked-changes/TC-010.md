## What was built

- `integrations/openrouter.py` (WP5): the adapter. 402, 403, 404 and 429, and every 5xx,
  are `QuotaOrUnavailable` and lead to the labelled fallback, never an error page; the
  model stage gives the route a cooldown of max(60 s, Retry-After). Timeouts and transport
  errors are `TransportFailure`; off-shape bodies `Malformed`; a request over 10,000 bytes
  is refused without a call and logged. `uniqueItems` is dropped from the schema copy sent
  (measured: the grammar engine behind the approved endpoints rejects it); `core.ideas`
  still enforces it.
- `planner/prompting.py` and `planner/prompts/select.v{1,2}.md`: the request (CONTRACTS §6).
- `planner/model_stage.py`: one open request (the hosted slot), the provider gate, the
  deadline guard. `ProviderName.OPENROUTER` and `CacheNamespace.MODEL` added to
  `planner/ports.py` for the gate key; the model is never cached.
- `main.py`: the adapter is wired whenever `OPENROUTER_API_KEY` is set (the unprefixed
  name the Fly secret carries); `/readyz` reports `model: ready` only then.
- Copy (the reviewer's rule): "up to three ideas" already; the weather line, the print
  context and the historical notice now say "forecast"; nothing says "safe" or
  "verified place". Board wording unchanged. The interests hint and DEPLOYMENT §1.1 carry
  the privacy sentence with the basis above.
