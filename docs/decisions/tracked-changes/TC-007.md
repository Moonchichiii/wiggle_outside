## The licence outcome

**Fontshare Font Licence (FFL) 2.0:** self-hosting the faces on our own site is
permitted; **putting the font files in a public repository is not.** DESIGN-SPEC §1.2
check 2 anticipated exactly this case, and its contingency is what we do:

- `.gitignore` excludes `frontend/fonts/*` and admits only `README.md`, so a `git add -A`
  cannot pull the binaries in.
- `frontend/fonts/README.md` records the origin (fontshare.com, the Indian Type Foundry),
  the licence, the rule, and how to work locally.
- `README.md` says the same at the top level, because someone cloning the repository will
  otherwise wonder why the design looks different.
- `Dockerfile` copies `frontend/fonts/` in the frontend stage, so the fonts reach the
  image when the build context supplies them and are simply absent when it does not.
- `.dockerignore` deliberately does **not** exclude them, with a comment saying why.

The faces are served **unchanged**: no subsetting, no re-encoding, no renaming.

## The three checks

1. **Glyph coverage: passes in full.** `scripts/check_fonts.py` reads each character map
   and compares it with the DESIGN-SPEC §1.2 set plus the copy deck's `·` and `…`. Cabinet
   Grotesk 465 glyphs / 405 codepoints; Switzer 386 / 385. No gaps in English, Swedish,
   French or the typographic marks.
2. **Licence:** above.
3. **Layout shift: cancelled at the source rather than measured and accepted.** Against
   the real Segoe UI on the build machine, Switzer's x-height is 6.2 % larger and its line
   box 7.5 % shorter; Cabinet's line box is 13.5 % shorter. `tokens.css` declares
   metric-matched fallback faces whose `size-adjust` and ascent/descent/line-gap overrides
   are computed from these files' own metrics, so the fallback occupies the webfont's box.

## Two differences from what DESIGN-SPEC §1.2 assumed

| §1.2 said | What arrived |
|---|---|
| `CabinetGrotesk-Extrabold.woff2`, ≈ 21 KB, one static weight | `CabinetGrotesk-Variable.woff2`, 41.9 KB, `wght` 100–900 |
| ≈ 64 KB in total | 85 KB in total |

Functionally fine — weight 800 is inside the variable range — but the §1.2 figures were
estimates from screenshots, and the preload decision ("likely Switzer only") should be
revisited against 85 KB rather than 64 KB. Recorded, not decided.
