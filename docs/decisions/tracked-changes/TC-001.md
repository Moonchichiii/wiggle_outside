# TC-001 — User-facing energy label "High", internal value `energetic`

| Field | Value |
|---|---|
| Change | The energy level reads **"High"** in every user-facing surface; the internal enum value, form value, catalogue value and model-facing value stay `energetic`. |
| Reason | Round 8.18 set the copy to "Gentle / Moderate / High" but no document ever stated the value-to-label mapping, and two lines in PLAN.md still showed "Energetic" as user-facing copy. An unstated mapping is unenforceable: an agent could reasonably render the raw value or store the label. |
